# Talenda

Système de gestion scolaire (School Management System) SaaS multi-écoles :
inscriptions, scolarité et caisse, notes et bulletins, vie scolaire,
communication avec les familles.

Le projet en est à la phase de conception. L'architecture produit et
technique de référence est dans [`docs/PRODUCT_ARCHITECTURE.md`](docs/PRODUCT_ARCHITECTURE.md).
